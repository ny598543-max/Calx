# 🧮 Calx - Smart Web Calculator

## 🚀 Overview

**Calx** is a modern and responsive web-based calculator designed to perform fast and accurate calculations with a clean and interactive user interface. It provides a smooth user experience and is built using powerful frontend technologies.

---

## ✨ Features

* ➕ Basic Arithmetic Operations
* ⚡ Fast & Accurate Calculations
* 🎨 Clean and Attractive UI
* 📱 Fully Responsive Design
* 🖱️ Easy to Use Interface

---

## 🛠️ Tech Stack

* 🌐 HTML5
* 🎨 CSS3
* ⚙️ JavaScript

---

## 📂 Project Structure

```
calx/
```

## ⚙️ How to Use

1. Clone the repository
2. Open `index.html` in your browser
3. Start calculating instantly 🎯
